EC20 Toolbox v1.6.1 — 短信自动转发
=================================

入口：https://192.0.2.10:8788/#forwarding（统一登录、HTTPS、CSRF）。
首次部署默认总开关关闭，没有预置目标；这次验收不向任何真实号码或外部 Webhook 发送短信。

规则
- 转发方式点击「＋ 添加转发方式」按需添加 Webhook / EC20 短信；初始不选，两种都添加时显示两个配置区。
- 每条规则最多30个发件号码/标识、30个内容关键词，最多20条规则。
- 发件标识精确匹配，国内手机号的 +86 / 0086 / 86 写法归一化；支持 10010 等服务号码。
- 内容按包含匹配，不区分大小写；组内任一匹配，两组可选 OR（任一满足）或 AND（全部满足）。
- 只有一组条件时只使用这一组；禁止空条件的“转发全部”。
- 可同时选择 Webhook 和短信渠道；不同目标分别投递，相同消息的相同目标合并。
- 总开关、单条规则分别控制。开启总开关或保存/重新启用规则只作用于之后新收到的短信。
- 不补发历史归档，不转发发件箱，不因服务重启重复投递已排队的短信。
- 规则变化时取消其未执行任务；关闭总开关取消所有未执行任务；已经启动/提交的请求可能完成。
- 默认不提供自动历史补发。预览只匹配模拟内容和计算短信分段，不投递网络、不发短信、不生成任务。

Webhook
- POST 固定 JSON；首版不是钉钉/企业微信机器人专有消息模板。
- 示例：
  {
    "event_id": "本次事件固定标识",
    "event": "sms.received",
    "rule_id": "规则标识",
    "message_id": "本地短信标识",
    "sender": "10010",
    "text": "模拟短信正文",
    "timestamp": "运营商原始时间（可能为空）",
    "received_at": "69首次归档时间",
    "forwarded_at": "本次投递时间"
  }
- 不附带 IMEI/IMSI、定位、登录密码或其他短信。接收目标可配置多组自定义 Header，包括 Authorization、X-API-Key 等。
- event_id、Idempotency-Key 和 X-EC20-Event-ID 固定，用于接收端去重。
- 网络错误、429/502/503/504 最多尝试3次；重试可能重复送达，接收端必须做幂等。
- 2xx 表示 HTTP 已应答，不保证下游业务处理或提醒成功。其他状态记录失败；不跟随重定向。
- 默认 HTTPS 并使用系统证书验证；不跳过证书验证。不使用环境代理，解析后校验并拨向同一 IP。
- HTTP 仅允许显式私网 IP。拒绝本机、回环、链路本地、多播及已列举的云元数据地址。
- 主机地址检查复用状态和只读 procfs，不增加网络管理权限；DNS 重绑定不能绕过逐次地址检查。
- 仅使用当前健康出口；有线故障后蜂窝为健康主出口时，Webhook 可以经蜂窝数据投递。
- URL/Header 值保存在 69 私有数据目录的 0600 文件中；列表仅展示脱敏主机地址和 Header 名称，不返回 Header 值。
  编辑规则时鉴权读取全部 Header，可增删改、显示/隐藏值；响应禁止缓存。URL 留空保留；Header 删除后保存即移除。
  旧 Bearer Token 自动兼容为 Authorization: Bearer …，打开配置不会重写磁盘。
  最多20项，名称最长128字节、值4096字节、总大小16KB；禁止重复、换行和控制字符。
  Content-Type（application/json）、Idempotency-Key、X-EC20-Event-ID 只读；连接控制 Header 不可覆盖。
  配置与日志不进入通用诊断包或 Git。

短信
- 使用现有 durable outbox 与 ModemManager SMS Create/Send；不操作串口、不改网络配置。
- 示例正文：
  [EC20-FWD]
  From: 10010
  原短信全文
- 使用 ASCII 标记避免仅因转发前缀把原 GSM-7 文本强制变成 UCS-2。
- 保留原文，不静默截断。沿用现有短信能力：最多3段，不支持的字符/超长内容记录失败。
- 转发前缀/来源号码也计入短信长度，实际计费以运营商为准。
- 默认每小时20条转发任务，可设1–60条；一条任务可能含多段。仍受现有每分钟5条提交保护。
- 有线主用、蜂窝备用健康、设备/SIM新鲜就绪且无通话/其他短信/定位设置时才提交短信。
- 蜂窝主用时等待，不为通知影响数据备用；恢复保护条件后继续处理，任务最长等待24小时。
- 发送句柄先持久化再提交；结果不确定时显示待核实，不自动重发。
- 带 [EC20-FWD] 标记的收到短信不再转发；目标与原发件号相同会阻止，以避免回环。
- 转发去重基于发件标识、原始时间和内容；没有原始时间的相同来源/内容会保守地合并。

运行边界
- 新短信先进入现有本地归档，再创建持久化转发任务；投递工作独立于原有5秒模块采样。
- 单个 Webhook 最多6秒，只阻塞转发工作协程，不占有模块采样/通话/短信/定位锁。
- 待处理任务上限500，保留最近1000条任务记录，页面显示最近100条；满队列明确记录未转发。
- 去重记录最多20000条；达到上限关闭转发并提示，重新开启从之后新短信开始。
- 不启动额外服务或端口，不扩大 polkit，不重启模块，不改变 SSH、自动备用、VPN 或 UAC 状态。
- MONDAY_ONSITE_CHECKLIST.txt 已列明现场联调前关闭自动转发，结束后再按需恢复。

验证
- Go race 覆盖匹配、空条件、回环、URL限制、私有配置、持久化、重启恢复、去重、额度、过期、
  Webhook载荷/幂等重试、短信网络保护、未知结果不重发和预览/演示无外部动作。
- 浏览器以本地演示验证配置、预览、保存、开启确认和关闭；生产只读验收，保持总开关关闭。
